Турнирный режим

Все делятся на группы, в каждой свои конкурсы. Из каждой группы дальше проходят лучшие, из прошедших собирается следующий тур — и так до финала.

Конкурсы

Баллы

Баллы сохраняются сразу. На экране они появятся только после «открытия» во вкладке «Эфир».

Оформление

Звук

Звук идёт из окна зеркала — то есть из телевизора по HDMI. Браузер включит его только после первого нажатия клавиши в этом окне: нажмите в нём F для полного экрана, и звук разблокируется.

Трек лежит в файле public/music/standby.mp3 — замените его, чтобы поставить свою музыку. Короткая запись зацикливается с плавной склейкой.

Музыка заданий

Положите свои файлы в папку public/music/tasks — программа раздаст их конкурсам по очереди: первому конкурсу первый файл, второму второй и так далее. Каждый трек зацикливается. Выбрать конкретный трек для конкурса можно на вкладке «Конкурсы».
